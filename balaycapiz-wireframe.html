Flow A — Design Notes

  • Search requires zero login — students browse anonymously
  • Campus selector defaults to Hercor Lawaan (primary segment)
  • Search pill collapses on scroll (Airbnb pattern)
  • Category chips are bedspace-aware, not generic rental categories
  • CAPELCO and BFP toggles are enabled by default — safety-first
  • Flood badge uses a 3-tier color system: Green / Amber / Red
  • Map uses price pins (not standard location pins) — Airbnb pattern
  • Save (heart) uses localStorage, no login required
Airbnb Influence: Pill search bar, category chip bar with icons, listing cards with image-first layout, save button overlay, map price pins, and progressive disclosure filter sheet.
Dormy PH Influence: Bedspace-specific room type, verified badge bar, gender preference filter.

Flow B — Design Notes

  • Safety card is BalayCapiz's core differentiator — absent from generic rental apps
  • Photo carousel follows AirBnb full-bleed, floating back/save button pattern
  • CTA bar uses native tel: and sms: protocols — no backend messaging server required
  • KYC Verified badge follows unidorms.ph trust-stack model
  • Reviews gated by tenancy proof — prevents defamatory or fabricated submissions
  • Electricity rate field enables crowdsourced CAPELCO compliance verification
  • Landlord Reply available per review (Q&A defense requirement)
  • Map uses Leaflet.js + OpenStreetMap — zero cost, aligns with proposal stack
Anti-Fake Review System: Tenancy proof is required before a review is published. Landlords receive a reply box. Platform does not take unilateral action — consistent with the TrikeRoxas 3-report threshold principle.

Flow C — Design Notes

  • 3-metric KPI row: Active Listings, Verified count, Days to Expiry
  • 30-day auto-expiry prevents stale listings (Q&A defense mechanism)
  • 1-tap Renew minimizes landlord friction for re-listing
  • BFP Certificate upload triggers an admin review before the badge appears publicly
  • CAPELCO toggle is a landlord declaration, cross-checked by student review data
  • Flood Risk is landlord-declared, cross-referenced with barangay flood maps
  • Contact number enables native tel: / sms: buttons — no chat backend needed
  • Pre-launch: admin team seeds 20–30 listings manually before public launch
Paabangan / Smapey Influence: Landlord dashboard with listing expiry tracking, vacancy management, and auto-archive modeled after Philippine boarding house management tools.
Zero-Cost Architecture: All file storage (BFP certs, photos, Student IDs) uses Supabase free-tier Storage (1 GB). Hosting on Vercel free tier. Monthly cost: ₱0.00.
